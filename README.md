# Live Overlay

תוכנה שמציגה נתונים מהלייב שלך בטיקטוק מעל השידור, ב-TikTok LIVE Studio או ב-OBS:
טבלאות דירוג (לייקים, מתנות, שיתופים), יעדים, מונה צופים והתראות קופצות.

## הורדה

הגרסה האחרונה נמצאת תמיד כאן: **[Releases › Latest](../../releases/latest)**

| מחשב | הקובץ להורדה |
|---|---|
| Mac עם מעבד Apple (M1 ומעלה) | הקובץ שמסתיים ב-`.dmg` |
| Windows (64 ביט) | הקובץ `Live-Overlay-Setup-…exe` |

אחרי ההתקנה התוכנה מתעדכנת לבד: גרסה חדשה יורדת ברקע ומותקנת כשסוגרים את התוכנה.

## פתיחה ראשונה

המערכת תציג אזהרה, כי התוכנה לא הופצה דרך חנות האפליקציות.

- **Mac**: אם מופיעה הודעה שלא ניתן לפתוח את התוכנה, פותחים את הגדרות המערכת › פרטיות ואבטחה,
  ולוחצים "פתח בכל זאת" ליד שם התוכנה.
- **Windows**: בהודעה "Windows הגן על המחשב שלך" לוחצים "מידע נוסף" ואז "הפעל בכל זאת".

## שימוש

1. מקלידים את שם המשתמש בטיקטוק ולוחצים "התחבר ללייב".
2. מעצבים את הווידג'טים.
3. מוסיפים כל ווידג'ט ל-LIVE Studio כמקור מסוג "קישור", לפי ההוראות שבתוכנה.

התוכנה צריכה להישאר פתוחה לאורך כל הלייב, באותו מחשב שממנו משדרים.

## חשוב לדעת

התוכנה אינה רשמית ואינה קשורה ל-TikTok או ל-ByteDance. היא קוראת נתונים ציבוריים של הלייב
דרך ספרייה לא רשמית, ועלולה להפסיק לעבוד אם טיקטוק משנה משהו. במקרה כזה תצא גרסה מעודכנת.
